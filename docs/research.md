# Research ledger — checked 2026-10-05

This ledger distinguishes publisher claims, inspected source/configuration, local measurements and proposed experiments. No paper speedup is an Equity/Exynos result. Revisions below identify what was actually inspected; moving `main` is not a dependency pin.

## Android capabilities

Follow the [NDK CPU feature guidance](https://developer.android.com/ndk/guides/cpu-features), [system tracing documentation](https://developer.android.com/topic/performance/tracing), and [ADPF documentation](https://developer.android.com/games/optimize/adpf). Perfetto/simpleperf permissions and individual GPU counters must be tested; documentation alone does not establish accessibility. The phone reports additional Arm features, but the initial portable binary only reports NEON/FMA. Its GLES identification is saved in the device snapshot; no Vulkan extension inventory, Xclipse compute run or Exynos NPU interface has been demonstrated.

Priority after the real CPU baseline: (1) read-only target-shaped I/O measurement, (2) trace actual expert routing/locality, (3) implement a bounded exact cache with short-read/eviction tests and resident logits comparison, (4) profile shared/compute costs and only then evaluate kernels/prefetch/speculation. Each stage has an independent failure criterion; techniques are not assumed to multiply their speedups.

## Local follow-up — 2026-10-06

The first read-only I/O proxy and a fifteen-minute resident fixture trial are complete; see [progress](progress.md). The proxy used 2 MiB random reads, whereas exact inspection of the target header now shows three separated banks per expert. The next replay must preserve this distinction. Bank shapes follow the pinned [Qwen3.5 MoE loader](https://github.com/ggml-org/llama.cpp/blob/6c59c40076c00eab49754dc955d7652d93f9e125/src/models/qwen35moe.cpp); K-block byte sizes follow [GGML definitions](https://github.com/ggml-org/llama.cpp/blob/6c59c40076c00eab49754dc955d7652d93f9e125/ggml/src/ggml-common.h). These inspected layouts establish byte ranges, not routing locality or cache hit rate.

The [Qwen3.5-0.8B hybrid fixture](https://huggingface.co/unsloth/Qwen3.5-0.8B-GGUF/tree/6ab461498e2023f6e3c1baea90a8f0fe38ab64d0) now passes host full-prefix replay and cancellation-recovery checks as well as mapped/allocated and chunked-prefill comparisons. This covers hybrid state clearing for a small dense-FFN model. It does not establish MoE, prefix reuse, speculative rollback or principal-model correctness.
